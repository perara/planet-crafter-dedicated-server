# Code of conduct

This project is a place to run game servers and fix them together. Be kind and be direct.

* Talk about the work, not the person. Disagree with the code, the design or the numbers.
* No harassment, insults, discrimination or sharing of other people's private information
  (names, addresses, Steam accounts, save files with players' names in them).
* Assume the other person is trying to help. Say what you tried and what you saw.
* Maintainers may edit, hide or remove comments, issues and pull requests that break these rules,
  and may block someone who keeps doing it.

To report a problem with someone's behaviour, use the private report on the Security tab of the
repository (SECURITY.md); say that it is about conduct.

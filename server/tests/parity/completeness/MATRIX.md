# Completeness matrices

Generated by `map.py gen` (regenerate it, do not edit). One row per group of the game, per RPC and per
component type, found by searching this server's code and tests, the parity sweep's own result files
and a census of a late-game save (group names and counts only).

Columns:

- **status**: `implemented` when every component the prefab carries that does host-side work in the game is named
  in the server's code; `partly` otherwise; `no prefab` for the groups the game has no prefab for.
- **tests**: `named` = the group id is written in a unit test; `family` = a component it carries is in a module with unit tests.
- **parity**: the sweep (`SWEEP.md`) ran the group on the real game host and on this server: the classes left
  (a: bug, b: deliberate, c: new safety rule, d: the game's randomness or timing, e: not comparable).
- **save**: objects of the group in the late-game save (in the world / in inventories).

Server banks

The server runs from one of two installed releases (banks). An update installs a release into the other bank and hands the running world over to it without disconnecting anyone; Roll back hands it back.

Update history

Live settings apply when saved; restart ones show what the server started with and change with pcds config and a restart. An empty field means the default.

Plugins

Plugins add commands, rules and reactions to the server without changing it. They live in the server's plugins folder; add one with pcds plugin install PATH. A plugin does nothing until you approve what it asks for; a folder put there is found within a few seconds, and a plugin can be approved, switched off and replaced while the world runs. A plugin that misbehaves is stopped and restarted, and switched off after five faults in a minute.

No plugins installed. pcds plugin new ID makes one; the guide is docs/plugins-guide.md.

Trusted publishers

A plugin is approved for the exact files you saw. A publisher can also sign its plugins (pcds plugin sign), and you can trust the publisher's key instead: what the key vouches for needs no approval and its updates run as they come, and whatever it asks for beyond waits for you. A signature that does not match the files counts for nothing. Remove a key and the plugins that ran only because of it stop.

Programs reading the event stream

An out-of-process plugin registers by asking for events (POST /api/plugins/events) and leaves by saying so, or after a minute of silence. It has no capabilities of its own: it can do what its token can. Give each program a token that opens only what it needs, below, instead of the admin token.

Tokens for programs

A token opens the requests of its scopes and nothing else (everything else needs the admin token), has a rate of its own, and can be removed at any time: it is refused from its next request. The server keeps only a hash of it, so the token is shown once, when it is made. Tokens are checked by the front: after an update that adds them, pcds upgrade --restart brings them in.

Kick, ban, unban

A name (any case) or client id. A ban also bans the SteamID (invite code) or IP (direct IP) of an online player; an offline name is banned as written. The access lists are under Config.
